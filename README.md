# Muhammed AbdElrhman Eisa — Portfolio

A personal portfolio showcasing web projects by Muhammed AbdElrhman Eisa (JuBa), an ERP and full-stack web developer.

## Project gallery

Projects are organized by category and displayed in a responsive gallery. Each card opens a project dialog with a cover image, description, project type, website domain, and link to the live site. The gallery supports keyboard navigation, reduced motion, and category filters.

## Running locally

This is a static website with no build step or package installation. Open `index.html` in a browser, or serve the repository with any static file server.

## Files

- `index.html` — page content, project cards, and shared project dialog.
- `style.css` — responsive layout and visual styling.
- `script.js` — filtering, project details, and dialog behavior.
- `img/` — project imagery; the website uses optimized WebP images.
